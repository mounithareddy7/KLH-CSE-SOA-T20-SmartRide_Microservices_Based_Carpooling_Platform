# 🎓 University Smart Ride
### A Smart Ride-Sharing and University Transportation Platform

University Smart Ride is a web-based platform designed to simplify transportation for university students. It allows students to find rides, offer rides, and access university bus route information in one place.

## ✨ Features

- 🔍 **Find a Ride:** Search for rides by pickup location, destination, and date.
- 🚗 **Offer a Ride:** Share ride details, available seats, timings, and vehicle information.
- 🚌 **University Bus Routes:** Access bus route and stop information.
- 👤 **User Authentication:** User registration and login functionality.
- 📋 **Ride Management:** Maintain ride and booking information.
- 🗄️ **Database Management:** Store user, ride, booking, bus route, bus stop, and attendance records.

## 🎯 Project Objectives

- To simplify transportation for university students.
- To provide a platform for finding and offering shared rides.
- To make university bus information accessible.
- To organize transportation data using a centralized database.
- To apply web development and database management concepts to a real-world problem.

## 🏗️ System Architecture

The project consists of three main layers:

1. **Frontend:** HTML, CSS, and JavaScript provide the user interface.
2. **Backend:** Java Spring Boot manages application logic and requests.
3. **Database:** MySQL stores and manages application data.

## 📂 Main Modules

- User Registration and Login
- Ride Search
- Offer a Ride
- Ride Booking
- University Bus Routes and Stops
- Bus Attendance Management

## ⚙️ Installation and Setup

### Prerequisites

- Java JDK 21
- MySQL Server
- MySQL Workbench
- Maven

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Create the Database

```sql
CREATE DATABASE university_smart_ride;
```

### 3. Configure MySQL

Update the database URL, username, and password in `src/main/resources/application.properties` to match your local MySQL setup.

### 4. Run the Application

Run `UniversitySmartRideApplication.java` from your IDE or execute:

```bash
mvn spring-boot:run
```

### 5. Open the Website

Visit `http://localhost:8080` in your browser.
